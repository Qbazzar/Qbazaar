# QBazaar — تقرير التدقيق الشامل (2026-09-30)

> **النطاق:** `qbazaar-api` (مع مراجعة ما يلزم من `qbazaar-web` و `deploy/`) — التشغيل، الأمان، الوظائف والرحلات، مطابقة PRD، لوحة الإدارة، الأداء وقاعدة البيانات، والهيكلة.
> **المنهج:** قراءة الكود فقط، بدون أي تعديل على المشروع. شغّلنا `pest` و `artisan about/route:list/event:list` بشكل read-only.
> **الفرع:** `HEAD = docs/v2-plan`، ولا يختلف عن `main` داخل `qbazaar-api/`، فكل النتائج تنطبق على `main` (أي على الإنتاج).
> **رموز التحقق:** ✅ مؤكَّد في جولة تحقق ثانية · ⬇️ مؤكَّد لكن خُفّضت خطورته · — لم يدخل جولة التحقق الثانية · **(يحتاج تأكيد)** = جزء لم نستطع إثباته من المستودع.
> **ملاحظة:** دمجنا المشاكل المكررة بين المحاور تحت معرّف واحد، وذكرنا المعرّفات الأخرى بين قوسين.

## 1. الخلاصة التنفيذية

1. **الحالة العامة:** الأساس جيد. الطبقات واضحة (Actions/Policies/Resources)، وعقد الأخطاء ثابت، والـ refresh tokens مصممة بعناية، وفي 353 اختبار. لكن **الحافات** (النشر، الأدمن، الرفع، الإشعارات) فيها ثغرات حقيقية.
2. **العدد بعد الدمج:** 61 مشكلة فريدة: **1 حرجة، 14 عالية، 32 متوسطة، 14 منخفضة**.
3. **أخطر 5 مشاكل:**
   - **XSS مخزّن** في صفحة الإعلان العامة عبر JSON-LD (`SEC-02`).
   - **رفع ملفات بامتداد العميل:** يسمح بـ XSS على origin الأدمن، وربما RCE على Apache **(يحتاج تأكيد)** (`SEC-01`).
   - **صلاحيات الأدمن غير مطبّقة:** أي موظف (حتى `support`) يحذف ويحظر ويعدّل كل شيء (`SEC-03`).
   - **تجاوز المراجعة:** تعديل إعلان منشور أو إضافة صور له تنعكس فوراً بدون مراجعة (`SEC-06`).
   - **الإنتاج لا يشغّل** طابور `low` ولا الـ scheduler، و `SCOUT_DRIVER=database` في القالب يكسر البحث بـ 500 (`RT-1`/`RT-2`/`RT-4`).
4. **خلل مخفي آخر:** كل listener مسجّل **مرتين**، فكل إشعار يصل مرتين (`F1`). والـ realtime لا يصل لأي عميل Bearer لأن `/api/v1/broadcasting/auth` غير موجود (`F3`).
5. **الاختبارات:** مع Meilisearch متوقف تنجح 221 من 353. مع `SCOUT_DRIVER=collection` تنجح 343، والعشرة الباقية تحتاج Meili حقيقي. **لا يوجد CI فعّال** لأن `ci.yml` داخل مجلد فرعي يتجاهله GitHub.
6. **هل الأساس صالح نبني عليه V2؟** **نعم، بشرط** إنهاء مرحلة **M0** أولاً، أي الإصلاحات الحرجة في الأمان والتشغيل (جدول القسم 10).
7. قبل أي شغل مالي (M1b: orders/wallet/commission) لازم ثلاثة أشياء: **انتقالات Offer مقفولة بـ `lockForUpdate`**، **صلاحيات أدمن حقيقية**، و **سجل تدقيق يسجّل الأدمن الفاعل**.

## 8. الهيكلة وجودة الكود

**الواقع:**
- **الطبقات:** `Controllers → Actions/Services → Models`، ولا توجد طبقة `Repositories`.
- **الـ controllers:** 40 من 64 تستعلم Eloquent مباشرة، و 23 من 45 controller API بلا Action ولا Service.
- **أفضل وحدة:** Offers (actions صغيرة، DI، Policy، Resource، `afterCommit`).
- **أضعف الوحدات:** Ads CRUD، Reviews، Support، Categories، ولوحة الأدمن بالكامل (المنطق داخل الـ controllers).

| ID | الخطورة | المشكلة |
|---|---|---|
| ARCH-02 (+F18) | متوسطة | الاختبارات غير معزولة (تحتاج Meili). الـ CI كان يشغّل Meili كخدمة، لكن الـ CI نفسه غير فعّال (RT-5) |
| ARCH-05 | متوسطة | رموز أخطاء في العقد لا تُرمى أبداً: `AD_006`، `AD_009`، `AD_INVALID_TRANSITION`… و `status` داخل `Ad::$fillable` |
| ARCH-06 | متوسطة | منطق في الـ controllers ومكرر: التعليق في موضعين، وأهلية التقييم داخل الـ controller |
| ARCH-11 | منخفضة | كل 404 غير مطابق يرجع `AD_001`، و `FORBIDDEN` خارج الـ enum والعقد |
| ARCH-12 | منخفضة | انحراف بين config والحدود الثابتة (title 120 مقابل 100، price)، وثلاث حزم Spatie غير مستعملة |

### القواعد الملزمة للكود الجديد (V2)

1. **المسار لكل دومين:**
   `Controller` (رفيع: resolve → `authorize` → Action واحد → Resource)
   → `Actions/<Domain>/<Verb><Noun>Action`
   → `Services/<Domain>/*`
   → Query/Repository class للقراءات المتكررة
   → `Model`.
   الأدمن يستدعي نفس الـ Actions، **ولا يكتب حقل status مباشرة أبداً**.
2. **المدخلات:** `FormRequest` → DTO (`spatie/laravel-data`). كل الحدود تأتي من `config('qbazaar.*')`، لا أرقام ثابتة.
3. **الأخطاء:** `throw new DomainException(ErrorCode::X)`. أضف الرمز في `ErrorCode.php` **و** `qbazaar-contracts/error-codes.md` (مثل `ORDER_0xx`، `WALLET_0xx`). ابقِ على قاعدة 404 بدل 403 للموارد الخاصة.
4. **المخرجات:** دائماً API Resource (snake_case، تواريخ ISO-8601، المبالغ decimal string + currency)، و `Resource::collection($paginator)`.
5. **State machines:** enum + `canTransitionTo()`. الانتقال داخل `DB::transaction`، مع `lockForUpdate()`، والأحداث بعد الـ commit. **إلزامي** لـ Order و Settlement و Offer.
6. **المال:**
   - أعمدة `decimal(12,2)`.
   - محفظة = ledger append-only، وليس عمود رصيد قابل للتعديل.
   - نسبة العمولة تُحفظ snapshot على الطلب.
   - الإعدادات في `settings` + `SettingsService`.
7. **الأدمن:**
   - كل route معدِّل عليه `permission:` middleware.
   - كل صلاحية جديدة تُضاف في `RolesAndPermissionsSeeder`.
   - كل تغيير يُسجَّل بـ `causedBy(auth()->user())`.
   - نصوص الـ flash عبر `__('admin.*')`.
8. **i18n:** نصوص النظام والشات تُخزّن كـ `message_key + params`، لا نص إنجليزي ثابت.
9. **Listeners:** آلية تسجيل واحدة فقط (discovery **أو** يدوي)، مع اختبار يعدّ الـ listeners.
10. **الاختبارات:** feature test لكل endpoint (نجاح، صلاحية، validation، أخطاء الدومين)، وunit للـ services وstate machines. يجب أن تمر مع `SCOUT_DRIVER=collection`، ولا يُدمج شيء بدون CI أخضر.
11. **الرفع:** اسم الملف يولّده السيرفر دائماً، وتُحوَّل الصور عبر الطابور.

## 9. نقاط القوة

- **عقد أخطاء ثابت:** `ErrorCode` enum + `DomainException` + envelope مركزي في `bootstrap/app.php`، ومعه `ApiResponseWrapper` و `X-Request-Id`.
- **Refresh tokens ممتازة:** hash مملّح، و row id مضمّن، و cache lock مع `lockForUpdate`، و reuse detection يحرق العائلة، و access token مدته 15 دقيقة.
- **الملكية:** كل موارد المستخدم محمية بفحص ملكية، وترجع 404 بدل 403. الـ mass assignment آمن عبر `validated()`، ولا يوجد SQL خام من مدخلات المستخدم، والـ sort عبر whitelist.
- **OTP:** `random_int`، و `Hash`، و TTL 5 دقائق، و 3 محاولات، و cooldown.
- **وحدة Offers:** نموذج يُحتذى، والأحداث تُرسل `DB::afterCommit`.
- **أمان التزامن في العدّادات:** increment/decrement ذري، و `Cache::add` لتحديد معدل المشاهدات، و unique على المفضلة.
- **الفهارس:** فهارس مركّبة صحيحة لأنماط الـ feed والمحادثات والرسائل.
- **الكاش:** featured/similar/suggestions تخزّن ids فقط.
- **البحث:** `AdSearchService` يتدهور بلطف عند انقطاع Meili (في وضع meilisearch)، وإعدادات Meili متوافقة مع الفلاتر.
- **لوحة الأدمن:** بنية متسقة (فلاتر، بحث، ترقيم، eager loading)، و CSRF، ولا `{!! !!}` غير آمن. الانتقالات مركزية في `AdModerationService`.
- **قالب الإنتاج:** `APP_DEBUG=false`، و secure/encrypted session. لا أسرار متتبّعة في git.
- **الاختبارات:** 353 اختباراً، و 343 تنجح مع driver غير Meili. الفروع الخمسة دُمجت بنظافة.
