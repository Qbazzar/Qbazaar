# Fonts

The Google Fonts files of Poppins, IBM Plex Sans Arabic, Montserrat, Story Script, Dancing Script, Acme, DM Sans, Instrument Serif, Cairo and Geist Mono (latin subset, or arabic for IBM Plex Sans Arabic and Cairo), loaded by `index.ts`. Each family is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org); the copyright notice is inside each file.

To add a weight, download the subset file Google Fonts serves for it (`fonts.googleapis.com/css2?family=...`), name it `family-subset-weight.woff2` and add it to the family's `src` in `index.ts`.
